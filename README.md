# Заявка на строительные материалы

Консольное приложение на Node.js для формирования заявки на строительные материалы.
Учитывает регион поставки, группы товаров и логику удержания клиента: при отказе
предлагает более дешёвый аналог из той же категории, а если выбран самый дешёвый
товар — пересчитывает его со скидкой 5%.

## Запуск

```bash
node index.js
```

или

```bash
npm start
```

Требуется Node.js версии 16 и выше. Внешних зависимостей нет.

## Как работает

1. Пользователь выбирает регион (Санкт-Петербург, Москва, Краснодар).
2. Приложение выводит список материалов с ценами для выбранного региона.
3. Пользователь выбирает товар и указывает количество.
4. Показывается предварительный заказ и вопрос «Оформляем заявку? (y/n)».
5. При согласии заявка сохраняется в JSON-файл в папке `orders/`.
6. При отказе срабатывает логика удержания:
   - определяется категория выбранного товара;
   - в этой категории ищется самый дешёвый товар для выбранного региона;
   - если найден более дешёвый аналог — он предлагается клиенту;
   - если выбранный товар уже самый дешёвый — цена пересчитывается со скидкой 5%.
7. Если клиент соглашается на предложение — заявка также сохраняется в JSON.

## Структура

```
data/catalog.json   каталог материалов: регионы, категории, цены
src/catalog.js      загрузка каталога и выборки по региону/категории
src/prompt.js       обёртка над readline для ввода с клавиатуры
src/order.js        логика удержания клиента и сохранение заявки
index.js            сценарий работы приложения
orders/             сюда сохраняются оформленные заявки
```

## Данные

Каталог содержит 6 категорий и 12 товаров с ценами для трёх регионов:
Утеплитель, Газобетон, Кирпич, Сухие смеси, Кровля, Пиломатериалы.
